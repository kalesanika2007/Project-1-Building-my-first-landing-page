# \# Clarity

# &#x20;

# A polished, responsive landing page for \*\*Clarity\*\* — a fictional productivity product that helps college students complete distraction-free focus sessions and understand how much focused work they actually do.

# &#x20;

# This is a practice project. It builds only the marketing website — not a working application.

# &#x20;

# \*\*Live site:\*\* https://kalesanika2007.github.io/Project-1-Building-my-first-landing-page/

# &#x20;

# \## Product

# &#x20;

# Clarity helps college students complete distraction-free focus sessions and see how much focused work they actually do.

# &#x20;

# \## Target user

# &#x20;

# College students aged roughly 18–24 who struggle with distractions while studying or doing deep work.

# &#x20;

# \## Primary goal

# &#x20;

# A visitor should understand what Clarity does within a few seconds, and be encouraged to click \*\*Start Focusing\*\*.

# &#x20;

# \## Main user journey

# &#x20;

# Visitor opens the website → understands Clarity → sees why it's useful → understands how it works → builds enough trust → clicks \*\*Start Focusing\*\*.

# &#x20;

# \## Pages

# &#x20;

# \- \*\*`index.html`\*\* — the main landing page

# \- \*\*`login.html`\*\* — a fictional login screen linked from the nav and final CTA. It's demo-only: the form never submits, stores, or transmits any data — it just shows a confirmation message client-side, and says so on the page.

# \## Page structure (`index.html`)

# &#x20;

# 1\. \*\*Navigation\*\* — Clarity logo, Features, How It Works, Pricing, Login

# 2\. \*\*Hero\*\* — benefit-focused headline, one supporting paragraph, primary CTA ("Start Focusing"), secondary CTA ("See How It Works"), and a mock product dashboard visual

# 3\. \*\*Features\*\* — Focus Timer, Distraction Blocking, Daily Analytics, each with a short explanation

# 4\. \*\*How It Works\*\* — three steps: Choose a focus session → Block distractions → Review your progress

# 5\. \*\*Social Proof\*\* — three fictional student testimonials, clearly labeled as demo/placeholder content, not real endorsements

# 6\. \*\*Pricing\*\* — Free and Pro, kept simple

# 7\. \*\*Final CTA\*\* — encourages the visitor to start their first focus session

# 8\. \*\*Footer\*\* — basic product navigation

# \## Design direction

# &#x20;

# Modern, minimal, premium, and youthful without looking childish. Strong typography (Fraunces for headlines, Inter for body), generous whitespace, clear visual hierarchy, and a single distinctive visual idea (the dashboard mockup) rather than decorative filler. Built mobile-first, with comfortable tap targets, readable wrapping, and no competing primary buttons.

# &#x20;

# \## Tech stack

# &#x20;

# \- Plain HTML + CSS, no build step or dependencies

# \- Fonts: \[Fraunces](https://fonts.google.com/specimen/Fraunces) (headlines) and \[Inter](https://fonts.google.com/specimen/Inter) (body text) via Google Fonts

# \- Hosted on \[GitHub Pages](https://pages.github.com/)

# \- Visitor analytics via \[Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) (privacy-friendly, no cookies)
