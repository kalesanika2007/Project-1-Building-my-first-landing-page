# Clarity

A landing page for **Clarity** — a fictional productivity app that helps students block distractions and complete focused study sessions.

This is a practice project built to learn how to communicate a product idea through structure, hierarchy, copy, and design — not to build the actual application.

**Live site:** https://kalesanika2007.github.io/Project-1-Building-my-first-landing-page/

## About the project

Clarity is aimed at college students who get distracted while studying. The page walks a visitor through a simple journey:

1. **Attention** — what is this?
2. **Value** — why should I care?
3. **Understand** — how does it work?
4. **Trust** — why should I believe it?
5. **Action** — start a focus session

## Sections

- **Hero** — the core promise, with a before/after study-day timeline
- **Features** — the four things Clarity actually does
- **How it works** — a 3-step process
- **Testimonial** — social proof from an early user
- **Footer**

## Tech stack

- Plain HTML + CSS, no build step or dependencies
- Fonts: [Fraunces](https://fonts.google.com/specimen/Fraunces) (headlines) and [Inter](https://fonts.google.com/specimen/Inter) (body text) via Google Fonts
- Hosted on [GitHub Pages](https://pages.github.com/)
- Visitor analytics via [Cloudflare Web Analytics](https://www.cloudflare.com/web-analytics/) (privacy-friendly, no cookies)

## Running locally

No installation needed — it's a single static file.

```bash
git clone https://github.com/kalesanika2007/Project-1-Building-my-first-landing-page.git
cd Project-1-Building-my-first-landing-page
open index.html   # or double-click the file in File Explorer/Finder
```
